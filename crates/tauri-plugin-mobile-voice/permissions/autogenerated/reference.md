## Default Permission

On-device speech recognition: session commands, permission request, model download and voice event listeners.

#### This default permission set includes the following:

- `allow-status`
- `allow-requestPermission`
- `allow-downloadLanguage`
- `allow-start`
- `allow-stop`
- `allow-cancel`
- `allow-register-listener`
- `allow-registerListener`
- `allow-remove-listener`
- `allow-removeListener`
