# art-term 0.1.24 更新說明

本版以正式 0.1.23 為基礎，加入 Android 原生終端捲動，改善手指拖曳與放手後的慣性滑動。原有連線、指令輸入、語音與終端核心沿用 0.1.23。

## Android 原生捲動

- 一般終端畫面使用 Android ScrollView 呈現本機已接收的內容，拖曳與慣性由系統處理，不將閱讀手勢送成遠端滑鼠或方向鍵。
- 閱讀較早內容時，新輸出保留目前閱讀位置；停在底部時則跟隨最新輸出。拖曳期間暫緩更新文字，停下後套用最新內容。
- 保留原有配色、文字樣式與最多 5000 行本機捲動緩衝；可見 HTTP／HTTPS 連結短點複製，拖曳不觸發複製。
- 保留原有鍵盤與多行輸入入口，開啟輸入或連線管理面板時，原生閱讀區會隱藏讓出操作空間。

## 相容性與限制

本版只加入本機原生閱讀呈現，不新增遠端歷史代理、跨裝置歷史或分頁下載。原生文字區不顯示 xterm 游標，字形與換行可能與原終端不同。

全螢幕 TUI 使用的 alternate buffer、後續欄寬重排（例如旋轉螢幕）、內容超出原生傳輸上限或原生面板無法開啟時，沿用原終端顯示與手勢。欄寬重排後需重設或重新連線，才會重新嘗試原生呈現。切換分頁後原生閱讀區從目前尾端開啟，本機緩衝內容仍保留。

## 版本與驗證

App 版本為 0.1.24，Android 安裝編號為 1031，延續原簽章與應用程式識別碼。此安裝編號高於先前測試版，可直接覆蓋更新。

本次原生捲動候選版已由使用者實機確認捲動效果。相關 14 項測試、型別檢查、獨立程式審查，以及候選版 ARM64 APK、Kotlin 原生模組、簽章與 16KiB 對齊驗證通過。正式 0.1.24 的版本調整不代表另行完成 Windows 實機驗證。
