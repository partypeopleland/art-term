# art-term 0.1.33 更新說明

- 新增 Ubuntu 24.04 x86_64 終端機版，可在 Server、Desktop 或 SSH 下執行 `art-term`，不需要圖形桌面或另外輸入啟動解鎖密碼。
- 三區介面提供固定展開的連線樹、桌面預覽與多分頁終端，支援方向鍵、Enter、滑鼠及可編輯的快捷鍵設定。
- 終端支援時可顯示原生桌面圖片，點擊縮圖在右側放大，支援拖曳、滾輪縮放與關閉。自動預覽間隔為每次取圖完成後 30 秒；終端不支援圖片時，仍可把桌面工具指定給 AI。
- 右側滾輪依遠端程式的滑鼠模式分流，支援一般 Shell 歷史與 Codex 等程式的滾輪操作。

Codex 桌面工具的權限組合與重新連線行為另由 [Issue 8](https://github.com/partypeopleland/art-term/issues/8) 補齊跨平台測試與分析，本版未修改 Codex 的權限政策。同一 Shell 重複開啟的接管與歷史所有權仍由 [Issue 7](https://github.com/partypeopleland/art-term/issues/7) 追蹤。

既有連線設定與密碼保護的匯出檔可繼續使用。Android 安裝編號 1064，沿用原簽章。
