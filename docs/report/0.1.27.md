# art-term 0.1.27 更新說明

- **手機介面更緊湊**：Computers／Agents／Screens 分類可收合，既有工作直接以名稱按鈕連線，多筆工作可展開選擇，主機及分頁圓點顯示本機連線狀態。
- **滑動切換畫面**：固定頂列提供 Main／Connect，左右滑動時指示色條跟著移動；點 art-term 可看目前版本與完整更新紀錄。
- **全站外觀設定**：科技感、深黑、柔光、懷舊四種主題立即套用各頁與終端，並記住選擇。
- **連線設定集中管理**：齒輪設定頁統一提供新增連線、匯入與匯出，主畫面保留工作連線操作。
- **語音預覽更彈性**：可選右側文字預覽或中央大區塊；錄音設定維持同列高度，支援的裝置預設允許中英文切換。快速鍵也重新排列。

- **連線結束與滑動修正**：Connect 尚未連線時也能右滑回 Main；輸入 `exit` 結束後回到「選擇連線」，清除舊終端畫面。
- **燈箱開啟時機修正**：保留文字燈箱偏好，連線時不會自行彈出；開始錄音、手動開啟或切換燈箱模式時才顯示。

Android 安裝編號 1050，沿用原簽章，可覆蓋更新並保留連線設定。本版先完成介面調整與上述修正，其他功能穩定性持續改善。
