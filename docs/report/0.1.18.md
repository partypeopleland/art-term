# 0.1.18 release note

## 差異

連線保存改為唯一 `connections.toml`。Windows 讀寫 EXE 旁或明示 `--config`，Android 讀寫 operator root；缺檔、空白或空清單正常啟動，第一次成功新增／匯入才保存。新增、修改、刪除與匯入一次寫回 schema 5，名稱、分類、能力及平台保護的憑證密文同檔。schema 2／3／4 只作相容輸入。舊 Host JSON、catalog fallback、私有 bootstrap 不再作啟動來源；詳 [connections](../refarch/connections.md)。

## 遷移

0.1.17 升級前先用舊版匯出，再於新版匯入；跨裝置含憑證檔必須以密碼加密，目的裝置重新以本機金鑰保護。舊 JSON、DPAPI／operator Keystore／marker 保留，不自動遷移或輪替 key。Android 使用原簽章更新，不清 App data。詳 [transfer](../refarch/connection-transfer.md) 與 [credential storage](../refarch/credential-storage.md)。

手動改檔先關 App；外部刪改會使過期 snapshot／保存拒絕，沒有 watcher 或跨程序鎖。

## 本版驗證範圍

- Windows 產品來源 `c07eef2`；Android 後續 key-loss guard `4c50e66`，交付紀錄 `e466cc5`。Android 同時檢查新 TOML／舊 JSON／marker，避免既有資料存在但 key 遺失時建立替代 key。
- 本版自動檢查、Windows／APK 建置及原簽章檔案驗證通過；真 Windows GUI 已測缺檔、空白、空清單、建立首筆、刪檔、原生選檔匯出／匯入及重開保存。
- APK 僅完成原簽章、ARM64、API 24／36、16 KiB 對齊、非 debug 及無預設連線 asset 檢查，未宣稱手機執行通過。手機首開／匯入／Keystore／觸控／背景及 Owner 兩平台驗收仍待。
- 本次未重跑正式 Host HTTPS／WSS 終端與桌面，過往 Host 測試不代表本版結果；兩平台 Owner 驗收前不合 main。
