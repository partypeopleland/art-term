# art-term 0.1.28 更新說明

- **獨立畫面設定**：Screens 可保存 instance-mcp 名稱、網址與加密認證，在齒輪的畫面設定新增、編輯、測試與刪除。
- **App 直接取得畫面**：預覽由 App 直接連線 instance-mcp，不再經受控端傳回圖片；各終端分頁可分別選擇、切換或停止預覽。
- **桌面指派給終端**：選擇 Screen 後，同一個 Shell 與支援的 coding CLI 可操作該桌面；切換或取消時同步更新，不必預先設定固定 MCP，也不需要由 App 啟動 Codex。
- **結束連線自動關頁**：修正使用主機歷史畫面後，Shell 結束仍留下空白分頁的問題；退出後直接關閉該分頁。

Android 安裝編號 1054；沿用原簽章，可覆蓋更新。既有主機連線保留；新工具入口需建立新的 Shell 連線才會載入。

## Windows 開發版

- 同步分類連線、全頁設定、四種主題、軟體資訊與獨立 Screens；左側清單及桌面預覽可調整大小。
- 終端改用 xterm 直接顯示輸出與原生捲動，移除歷史文字覆蓋層。
- 連線匯入、匯出可同時包含 Screens；選擇含憑證時，以密碼保護管理憑證與 Screen token。亦可只搬移 Screens，舊版主機搬移檔仍可匯入。

以上為 Windows 開發分支更新；Android APK 尚未重新建置，語音移植留待下一階段。
