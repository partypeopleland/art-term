# art-term 0.1.38 更新說明

- Windows 桌面版終端新增分割視窗：可將終端切成多個窗格，各窗格可各自連線不同的遠端主機或 Shell；窗格上按右鍵可操作，分割快捷鍵可在設定中調整；關閉窗格會一併結束該窗格的遠端 Shell，並更新連線清單。
- Android 版終端支援長按選取並複製文字，輸出持續更新時不會中斷選取。
- Windows 終端新增 Alt+C 複製、Alt+V 貼上快捷鍵，反白選取的文字會自動複製到剪貼簿。
- 手機版設定改為第四個滑動頁面，左右滑動切換更順暢。
- Linux 終端機版修正主機歷史暫時讀取失敗後可自動恢復，以及憑證庫偶發無法重新開啟的問題。

既有連線設定與加密匯出檔可繼續使用。Android 安裝編號 1069，沿用原簽章。
