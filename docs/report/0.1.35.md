# art-term 0.1.35 更新說明

- Windows 與 Android 將 Computer、Agent、Screen 整合到同一個連線清單。按右上角新增圖示才展開表單，並用同一行的類型圖示與單選按鈕選擇類型。
- 連線清單提供編輯、測試與刪除操作。儲存及測試結果改用短暫提示顯示，Windows 左側選單也加寬，方便閱讀較長的網址。
- 同類型連線可拖曳排序，左側選單同步套用並保存順序。分類固定依 Computer、Agent、Screen 排列，不能跨類型拖曳。
- 左側原本的 codex、openab-pty 類型文字可設定顯示名稱，支援中文，最多 20 個字。留空時沿用預設名稱，Ubuntu 終端機版也沿用名稱與排序設定。
- 移除右上角的「啟動 Codex」按鈕。請直接在終端輸入要執行的指令。
- 手機左右滑動納入 art-term 首頁，可在首頁、連線及終端之間切換。
- art-term 的 Host Shell 啟動工具預設替手動輸入的 `codex` 加上 `--no-alt-screen`，其他參數照常保留，讓終端保留可捲動的輸出。更新 Host 啟動工具後，下次啟動 Codex 生效；更新 App 不會自動替換遠端工具，也無法補回先前全螢幕程式未留下的歷史。

既有連線設定與密碼保護的匯出檔可繼續使用。Android 安裝編號 1066，沿用原簽章。
