# APK UI 回歸測試：2026-10-14

已建立可重跑的 Linux/KVM APK UI 矩陣，沿用既有 Android Suite 與共用 Runtime fixture，並由 agy 審查案例缺口。採用介面 × 操作 × 狀態、等價類、邊界值、取消／錯誤路徑與相鄰功能組合。

本次依完整流程、獨立歷史群組與導航群組分開執行，彙總 **48 項紀錄：43 PASS、2 FAIL、3 BLOCKED、0 NOT_RUN**。包含一項 SETUP-TRANSFER 前置準備，不能把它當作額外產品功能覆蓋。這不是一次完整流程全綠，也不表示所有 UI 組合已窮舉。

## 兩個尚未修正的 UI 問題

- **KEY-IME**：軟鍵盤隱藏時，左／上／下／右四鍵皆把系統 `mInputShown` 由 false 改成 true。鍵盤原本顯示時，四鍵皆維持顯示。八種組合均實際操作，測試收尾恢復鍵盤狀態，沒有讓此失敗干擾後續案例。
- **READ-06**：新工作的大量歷史可使用原生 ScrollView 捲動；開關 Shell 清單、建立第二個工作並切回第一分頁後，原生 ScrollView 不再可用，畫面退回 xterm。另以 TAB-04 確認 active 分頁、遠端名稱與 composer 實際送達目標一致，排除測試誤選工作。這個失敗不等於歷史資料遺失，也不代表 fallback 的所有捲動方式已失效。

測試過程沒有為了取得綠燈修改產品行為；目前語音 swap 產品改動保留在工作分支。兩個失敗以固定 ID 留在後續回歸入口。

## 已通過的重點

- 單一工作180行虛構 ls 類輸出、真 ADB 拖曳與截圖位移；拖曳不送遠端輸入。
- 閱讀歷史時追加輸出不跳到底；WSS 中斷後同 token/cursor 恢復；手動重新連線同一 Shell 後，新的原生 snapshot 仍有舊資料且可拖曳。
- gear 在文字預覽／設定 radio 間 swap；tap/hold 與語言選項可操作，原生閱讀區維持可見；設定重啟保存；Composer／連線管理的遮擋保護。
- 首頁／分類／刷新、連線 CRUD／認證失敗／取消／邊界、Shell 名稱與衝突、Unicode、逐個快速鍵 bytes、Ctrl、CLI、分頁與最後頁關閉。
- 真 PNG 首圖／兩次30秒週期／不同圖片的手動更新、隱藏／顯示／分頁隔離；Android HOME33秒與回前景。
- 真 SAF 加密匯出／匯入、取消／錯密碼／重複更新、metadata-only 與補憑證；同 debug APK install-r。
- 語音元件26項測試通過；Vue／TypeScript typecheck、Python 編譯與 diff 格式檢查通過。

- APK：versionName 0.1.24，x86_64 debug + openab-fixture；目前語音設定 swap 程式碼。不是手機 ARM64 release 或原簽章升級驗收。
- Android34 default x86_64、專用 KVM AVD、412×915／160dpi；真 APK／WebView／Tauri IPC／Rust TLS/WSS／Keystore／DocumentsUI。
- 只有對端 Runtime 模擬；不執行 ls 或 CLI，使用虛構終端輸出及有效 PNG。沒有產品 IPC 假回傳、JS click、真 NUC 帳密或現有手機操作。
