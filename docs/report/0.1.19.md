# 0.1.19 release note

## 差異

App 改用未修改的官方 openab-pty：管理呼叫走 HTTPS，終端輸入輸出走 WSS attach，移除本專案的自訂 Runtime 補丁與相容標記。連線身分改用官方名稱／generation 與原 attach token 恢復短暫斷線，沒有跨服務重啟的原子工作身分比對；契約與限制見[連線與工作](../refarch/sessions.md)。

桌面預覽改由 App 在相同 Runtime 上建立專用截圖 Shell，呼叫 Host 端 helper 經既有 instance-mcp 取得圖片，再由該 Shell 的 WSS 回傳。App 端不再使用 SSH 桌面 helper、pin 或首次 SSH 授權；Host 端 helper 為本專案腳本，官方 Runtime 不修改。桌面責任與準備見[桌面預覽](../refarch/desktop.md)與[桌面 helper](../refarch/runtime-desktop.md)。

helper 補上大圖分段傳送（8 KiB 分段、段間短暫停頓），避免單次突發輸出超過官方有界輸出佇列而缺段；圖片界限、nonce 標記與嚴格 Gap 丟棄不變。

## 遷移

既有 Host 以 `bash scripts/init-host.sh --upgrade-runtime` 遷移到官方 format 4：一次交換完整安裝目錄、逐位元保留認證，但會終止全部既有 PTY。中斷交易用 `--recover-upgrade` 復原；桌面啟用用 `--enable-desktop`，中斷用 `--recover-desktop`，停用用 `--rollback-desktop`。細節見 [Host 維護](../platforms/linux-host-maintenance.md)。

App 連線仍來自唯一 `connections.toml`（schema 5），本版無設定或憑證格式遷移；0.1.17 以前舊資料的搬移沿用 [0.1.18](0.1.18.md) 的匯出／匯入方式。

## 本版驗證範圍

- 產品來源 `cc367c6`，後續大圖修正僅改 Host helper。Windows ZIP 與原簽章 APK（`net.missart.artterm` 0.1.19／code 1019、ARM64、minSdk 24／targetSdk 36、16 KiB 對齊、無內嵌連線）已交付 NAS，回讀 SHA256 與本機一致。
- NUC（原生安裝）與 Hana（容器部署）均已切換到未修改官方 Runtime 並部署修正後 helper；真 Windows GUI 驗證終端、CLI、桌面首圖／自動／手動更新及大圖修正前後對照通過。
- Owner 於 2026-10-11 完成 Windows 與 APK 兩平台驗收並結案，本版已整合 main。
- 大圖缺段的直接原因屬有證據支持的推論（超出官方有界佇列），未直接捕獲 Gap frame；分段修正的實測證據與此區分保留於任務紀錄。
