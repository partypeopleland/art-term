# art-term 0.1.25 更新說明

- **修正語音設定被遮住**：按設定後，文字預覽區會切換成「點一下」與「按住說話」的模式選項，再按一次回到文字預覽。設定時仍可看到終端閱讀區，選擇的模式會保存。
- **修正快速鍵意外打開鍵盤**：上下左右與 Ctrl 等快速鍵會保留虛擬鍵盤原本的開啟或隱藏狀態，按鍵直接送出。
- **增加介面回歸測試**：涵蓋連線管理、分頁、輸入、語音設定、預覽，以及斷線重連後的歷史捲動，減少修改功能造成其他操作失效。

沿用 0.1.24 的 Android 原生拖曳與慣性捲動。Windows 與 Android 版本均為 0.1.25；Android 安裝編號增加為 1032，使用相同簽章的舊版可直接覆蓋更新。
