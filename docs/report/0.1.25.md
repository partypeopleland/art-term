# art-term 0.1.25 更新說明

本版延續 0.1.24 的 Android 原生捲動，修正語音設定被閱讀區遮住及快速鍵改變虛擬鍵盤狀態的問題，並建立可重跑的 APK UI 回歸測試矩陣。

## Android 操作修正

- 語音設定改為在原本的文字預覽區內切換：按設定顯示「點一下」與「按住說話」兩種模式的 radio button，再按一次恢復文字預覽。選擇模式會保存；開啟設定時原生閱讀區持續顯示，無須另開可能被遮住的選單。
- 修正按上下左右等快速鍵時，已隱藏的虛擬鍵盤意外打開。快速鍵直接送出對應按鍵，保留鍵盤原本開啟或隱藏的狀態；Ctrl 切換也不主動取得輸入焦點。明確按下鍵盤按鈕時仍可正常開始輸入。
- 保留已驗收的原生手指拖曳與慣性捲動；本版未變更原生捲動演算法或紀錄投影。

## APK UI 回歸保護

新增 48 筆測試案例矩陣（含安裝前置與環境限制案例），在 Linux Android 模擬器實際操作 APK。範圍包括 Host 管理、Shell 與分頁、指令與快速鍵、語音模式設定、桌面預覽、系統選檔、背景／旋轉，以及斷線、重連後舊內容的保留與拖曳閱讀。後端採可重現的 TLS/WSS fixture，原生 IPC、Keystore 與系統 UI 仍實際執行。

修正一項測試誤判：切換列表／分頁後，Android 14 的 accessibility 清單有時漏列原生閱讀區，但實際畫面仍可拖曳。測試現在可透過實際 Android View hierarchy 確認閱讀區，並持續要求實際拖曳、畫面變化及不送出遠端輸入；這項調整不代表曾修正原生捲動功能缺陷。

## 版本、相容性與驗證

Windows 與 Android App 版本均為 **0.1.25**，Android 安裝編號由 **1031 增加為 1032**。應用程式識別碼保持原值，Android 沿用既有固定 release 簽章；同簽章舊版可覆蓋更新。

功能程式碼在版本調整前已通過完整 APK UI 矩陣：**45 PASS、0 FAIL、3 BLOCKED**，以及前端 **268 項測試與型別檢查**。另以相同 APK 補驗四個方向鍵 × 鍵盤開／關八種情況，最終狀態與期間原生事件皆未出現相反狀態。這些功能證據來自 v0.1.24 標記的 x86_64 debug 測試包；不宣稱已對 v0.1.25 ARM64 正式包重跑相同模擬器流程。

三項環境限制為：完整裝置語音辨識、Windows 與 Android 雙向搬移，以及 ARM64 正式包覆蓋升級／OEM 鍵盤／Doze 實機操作。它們不計入 PASS。Windows 本版沒有另行實機 GUI 驗收；本機與 GitHub 正式建置結果須分別確認。測試矩陣目前為本機可重跑工具，尚非 GitHub Actions 必過門檻。

GitHub tag `v0.1.25` 觸發 Windows EXE／ZIP 與原簽章 ARM64 APK 建置；兩者成功後才發布 Release。本版起 GitHub Release 直接使用本文件作為更新說明。
