# art-term 0.1.26 更新說明

- **歷史按需載入**：新 Shell 統一由 tmux 管理，先顯示當前畫面，往上捲動再分批取得較早紀錄。關閉分頁或重開 App 後，可接回仍在執行的工作。
- **捲動位置更穩定**：閱讀舊紀錄、持續輸出及開關鍵盤時保留閱讀位置；位於底部時跟隨最新輸出。改善大量輸出時的連線恢復。
- **建立更簡單**：只保留「建立並連線」，自動產生簡短 Shell 名稱。
- **Codex 使用一般畫面**：右上角按鈕執行 `codex --yolo --no-alt-screen`，方便保留與閱讀終端歷史。

新建 Shell 需要主機安裝 tmux 支援檔，準備方式見[主機歷史設定](../refarch/terminal-history.md)。既有 Shell 可繼續連線，不會自動轉換。歷史保存在主機記憶體，上限 5000 行；主機重開、工作結束或程式清除歷史後無法保證恢復。

Android 安裝編號為 1048，沿用原簽章，可直接覆蓋更新並保留連線設定。公開版不內嵌私人連線資料；本次功能以 Android 驗收，Windows 暫停功能驗收。
